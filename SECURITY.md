# Security Policy

## Supported Versions

OMS Pro is a continuously deployed SaaS — there are no long-lived release
branches. Only the latest version running in production is supported with
security fixes.

| Version | Supported          |
| ------- | ------------------ |
| latest (production) | :white_check_mark: |
| older deployments   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, email the owner directly:

- **Email**: [bhankariwal@gmail.com](mailto:bhankariwal@gmail.com)
- **Phone/WhatsApp**: +91 99830 00552

Include as much of the following as you can:

- The type of issue and its impact
- Step-by-step instructions to reproduce the issue
- Affected URLs, screenshots, or proof-of-concept code
- Your assessment of the severity

You can expect an acknowledgement within 48 hours. We will keep you informed
of the progress towards a fix and may ask for additional information. Please
give us a reasonable time to address the issue before any public disclosure.

## Data Protection Commitment

Every subscriber company's data is isolated by company-scoped Row Level
Security. OMS Pro never shares, sells, or misuses subscriber data. The
platform brand appears on exported files as a small attribution line —
subscriber data itself is never exposed to other companies.
